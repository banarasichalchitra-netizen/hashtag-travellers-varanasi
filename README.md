# Hashtag Travellers Varanasi

A static website for Hashtag Travellers Hostel in Varanasi. It presents the hostel, listed amenities, the surrounding area, directions, FAQs, and a Hostelworld booking link.

## Website and publishing

GitHub Pages URL: https://banarasichalchitra-netizen.github.io/hashtag-travellers-varanasi/

GitHub Pages serves the prebuilt site from `docs/` on the `main` branch. To publish an update, replace the files in `docs/` and commit them to `main`.

The editable React project remains in the original Replit workspace. This repository contains its production build for GitHub Pages.
